# Aether Pixels Docs

Landing page for [docs.aetherpixels.com](https://docs.aetherpixels.com).

Each plugin's docs live in that plugin's own repository (GitHub Pages from its `docs/` folder) and appear here as a folder named after the repository, for example [docs.aetherpixels.com/slatecharts](https://docs.aetherpixels.com/slatecharts/) from [ahmad-farrag/slatecharts](https://github.com/ahmad-farrag/slatecharts).

To add a plugin: give its repository a lowercase name, turn on GitHub Pages for it (no custom domain), and add a card to `index.html`.
